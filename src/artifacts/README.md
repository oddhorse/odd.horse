# artifacts dir

this directory is for artifacts

artifacts list is registered in `/src/_data/artifacts.json`

```json
{
  "id": "my-artifact",
  "description": "Description shown to visitors",
  "url": "/artifacts/my-file.pdf",
  "type": "pdf",
  "dateAdded": "2025-12-31",
  "color": "#ff00bb"
}
```
